# 新套网银驱动（已归档，不用于生产）

这里的 `driver.py` 是 2026-10-29 前后的“通用驱动 + profile”实现，覆盖工行、中信、兴业三家。
2026-10-30 起三家银行的生产入口都改回旧套 `main.py`，新套此后没有生产调用方。

保留原因：

- 工行新套在 10-29 真机跑通过 11 次流水采集，登录态判定、下载排障、错误码设计比旧套细；
- 后续做旧套模块化（PIN 焦点校验、关闭看门狗、下载重试、错误码）时可以对照参考；
- `platform/tests/test_icbc.py`、`test_icbc_simulation.py` 仍按路径加载 ICBC 驱动做回归测试。

约束：

- **不再新增功能，不再维护第二入口**。生产任务只走各银行目录下的 `run_task.py` → `main.py`。
- 如果要从这里取代码，请移植到 `common/` 或旧套对应模块，而不是把 driver 入口接回生产。

共享框架 `common/collect/` 仍在原位置，测试和归档驱动都依赖它。
